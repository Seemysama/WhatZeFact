# 🎵 Musiques Libres de Droits pour WhatZeFact

Place tes fichiers `.mp3` dans ce dossier. Le pipeline en choisira un aléatoirement comme musique de fond.

## Où télécharger de la musique gratuite ?

| Source | Lien | Notes |
|---|---|---|
| **Pixabay Music** | https://pixabay.com/music/ | 100% libre, aucune attribution requise |
| **Mixkit** | https://mixkit.co/free-stock-music/ | Gratuit, pas d'attribution |
| **YouTube Audio Library** | https://studio.youtube.com (section Audio) | Libre pour YouTube, certains avec attribution |
| **Uppbeat** | https://uppbeat.io/ | 3 téléchargements gratuits/mois |
| **Bensound** | https://www.bensound.com/ | Certains gratuits avec attribution |
| **Free Music Archive** | https://freemusicarchive.org/ | Varie selon la licence |

## Conseils

- Choisis des morceaux **instrumentaux** (pas de paroles qui interfèrent avec la voix off)
- Privilégie des morceaux **courts ou en boucle** (30-60 secondes)
- Les genres qui marchent bien : lo-fi, jazz léger, électro douce, musique fun/quirky
- Le volume sera automatiquement baissé à -20dB pour ne pas couvrir la voix off
